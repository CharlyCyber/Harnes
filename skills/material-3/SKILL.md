# Material Design 3 — Skill de Diseño de Interfaces

> Skill especializada en **Material Design 3 (Material You)** para web y apps. Cubre sistema de color dinámico, tipografía, forma, componentes, theming, navegación, layout responsive y auditoría MD3.

## Capacidades

- **Sistema de Color Dinámico**: Token-based color scheme con `colorScheme`, colores primarios/secundarios/terciarios/neutros/error, y colores personalizados. Implementación de `lightColorScheme` / `darkColorScheme`.
- **Tipografía y Forma**: Type scale (display → label, 15 tamaños), font families, shape scale (none → full, 6 niveles).
- **Catálogo de Componentes**: 30+ componentes MD3 — App Bars, Bottom Navigation, Buttons, Cards, Chips, Dialogs, Navigation Bar, Navigation Drawer, Navigation Rail, Search, Sheets (bottom/side), Sliders, Snackbars, Switches, Tabs, Text Fields, Top App Bar, etc.
- **Theming y Dynamic Color (Monet)**: Generación de esquemas desde wallpaper, tonal spot colors, tokens semantic vs. tonal, light/dark mode automático.
- **Layout y Responsive**: Window size classes (compact/medium/expanded), canonical layouts, adaptive navigation, responsive grids.
- **Navegación**: Navigation Bar (mobile), Navigation Rail (tablet), Navigation Drawer (desktop), Internal navigation (tabs, search, carousel).
- **Auditoría MD3**: Checklist completa para verificar conformidad con especificación MD3.

## Uso

Activa esta skill cuando:
- Diseñes o implementes interfaces con **Material Design 3**
- Necesites **sistema de color dinámico** (Material You / Monet)
- Implementes **componentes MD3** (Compose, Flutter, o Web)
- Audites conformidad con **especificaciones MD3**
- Adaptes layouts responsive con **window size classes**
- Configures **theming completo** (light + dark + dynamic)
